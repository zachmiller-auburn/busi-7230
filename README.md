# Budget Boss — Crestline Coffee Co.

An interactive budgeting and forecasting simulation built for **BUSI-7230: MBA Core Accounting** at Auburn University.

Players take on the role of General Manager at Crestline Coffee Co., a fictional specialty coffee roaster, and navigate four quarters of real-world accounting decisions — from setting an annual budget to diagnosing variances, managing cash flow, and anchoring next year's plan.

## Play the Game

**[Launch Budget Boss](https://zachmiller-auburn.github.io/busi-7230/)** — no install required, runs entirely in the browser.

## What It Teaches

| Quarter | Topic | Concept |
|---------|-------|---------|
| Q1 | Budgeting | Build a defensible annual plan; navigate optimism bias |
| Q2 | Variance Analysis | Favorable vs. unfavorable variances; net OI impact = Rev variance − Cost variance |
| Q3 | Cash Flow | Why profit ≠ cash when receivables and prepaid inventory grow (indirect method) |
| Q4 | Forecast Anchoring | Anchor next year's budget to actuals, not to targets worked backward from a wish |

Each quarter includes **check-your-understanding questions** (5 pts) and a **strategic decision** (20 pts) for a total of 100 points.

## Features

- **Single-file, zero-dependency** — one `index.html` with inline CSS and JS; no build step, no framework
- **What-if mode** — after submitting, click any other option to preview how it would have played out (score stays locked)
- **Synced slider + number input** — set budgets by dragging or typing exact values
- **Quarter navigation** — revisit past quarters in read-only review mode via the breadcrumb bar
- **Mobile-first responsive design** — fluid typography, 360/480/640px breakpoints, safe-area support for notch devices
- **Accessible** — WCAG 2.1 AA color contrast, ARIA radiogroup/radio patterns, keyboard navigation, skip link, `prefers-reduced-motion` support
